# 36Stxdio — Creative Studio Website

An immersive, animation-driven creative studio website focused on interactive visuals, bold typography, and smooth user experiences.

36Stxdio explores modern frontend animation techniques through GSAP-powered interactions, canvas-based image sequences, and smooth scrolling to create an engaging digital experience.

## 🌐 Live Demo

**[Visit 36Stxdio](https://36stxdio.netlify.app/)**

## ✨ Features

- **Interactive Animations:** Smooth and engaging animations powered by GSAP.
- **Canvas Image Sequences:** Dynamic canvas-based visuals for immersive scrolling experiences.
- **Smooth Scrolling:** Enhanced scrolling experience using Locomotive Scroll.
- **Bold Typography:** Minimalist layouts with expressive typography.
- **Interactive Elements:** Engaging transitions and click-based visual effects.
- **Modern UI:** Clean, experimental design with a strong visual identity.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React 19 | Frontend development |
| Vite | Development and build tooling |
| Tailwind CSS | Styling and responsive layouts |
| GSAP | Animations and interactions |
| Locomotive Scroll | Smooth scrolling |
| HTML Canvas | Image sequence animations |
| JavaScript | Application logic |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/aadarshgit-dev/36Stxdio.git
```

### 2. Navigate to the project directory

```bash
cd 36Stxdio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### 5. Build for production

```bash
npm run build
```
